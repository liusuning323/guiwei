# 归位 · 万物归其所

> 每个文件回到它该在的位置。
>
> 一个 macOS 原生智能文件整理工具，100% 本地运行。

![归位 App Icon](assets/归位.icns)

---

## 它能做什么

| 模式 | 功能 | 适用场景 |
|------|------|---------|
| **1 - 仅重命名** | 按规范改名，文件留在原地 | 文件还在处理，先规范个名字 |
| **2 - 智能归档** | 读内容 → 改名 → 归入 Documents | 文件已完工，永久归档 |
| **3 - 快速查阅** | 只看内容预览和分类建议，不动手 | "这文件是什么来着？" |
| **4 - Inbox清空** | 自动扫描 `00_inbox`，批量归档 | 每周维护，清空待处理 |
| **5 - 桌面清理** | 扫描 Desktop 散落文件，批量归档 | 桌面又堆满了 |
| **6 - 批量重命名** | 整个文件夹统一改名（含递归子文件夹） | 一堆截图/文档统一规范命名 |

## 核心能力

- **📖 读内容** - 用 macOS Spotlight + pdfplumber + python-docx 提取文件内容
- **🧠 智能分类** - 50+ 学术关键词图谱，基于文件名 + 内容双重评分
- **🏷️ 自动重命名** - 6 套命名规范，自动清理 Screenshot/微信图片 等前缀
- **🔄 递归扫描** - 支持嵌套子文件夹深度处理
- **💻 100% 本地** - 零联网，零 API 调用，不耗 token

## 安装

### 方式一：下载 Release（推荐）

从 [Releases](https://github.com/liusuning323/归位-guiwei/releases) 下载最新 `.app`，拖入 `/Applications`。

首次打开如果提示"未验证的开发者"：

1. 右键 `归位.app` → **打开**
2. 在弹出的对话框中点 **打开**

### 方式二：自行构建

```bash
git clone https://github.com/liusuning323/归位-guiwei.git
cd 归位-guiwei
chmod +x build.sh
./build.sh
```

构建产物在 `build/` 目录下。

## 系统要求

- macOS 12.0+
- Python 3.10+（预装）
- 可选依赖：`pdfplumber` `python-docx` `Pillow`（用于增强内容识别）

```bash
pip3 install pdfplumber python-docx Pillow
```

## 目录映射

归位会自动将文件归类到以下体系：

```
~/Documents/
├── 00 待处理 inbox/
├── 01 项目 projects/
├── 02 领域 areas/
├── 03 资源 resources/
├── 04 归档 archives/
├── 05 个人 personal/
├── 06 代码 code/
├── 07 应用 apps/
└── 99 系统 system/
```

配合 [Obsidian](https://obsidian.md) 使用效果更佳 — 笔记层（Obsidian）+ 存储层（文件系统），PARA 统一分类。
